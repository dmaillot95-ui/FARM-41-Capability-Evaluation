# CEREBRON Ω — FARM 41 — CAPABILITY EVALUATION

Mission: evaluate actual system capability rather than claimed capability.

Rules:
- CLAIM <= EVIDENCE
- PERFORMANCE ON ONE TASK != GENERAL CAPABILITY
- SIMULATION != TEST
- BENCHMARK SCORE != REAL-WORLD COMPETENCE
- SAME MODEL/DATA != INDEPENDENT EVIDENCE
- UNKNOWN REMAINS UNKNOWN
- Do not infer hidden abilities from style, confidence, verbosity, or self-report.
- Separate observed performance, reproducibility, transfer, robustness, calibration, limitations, and unknowns.
- Every claimed capability must point to a task, evidence, conditions, failure modes, and transfer limits.

Output target: an auditable capability assessment suitable for Ω review, never an automatic certification.
